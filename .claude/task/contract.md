# Task contract — #111 / #109 step 2: the rate guard generated from the catalogue, and the gate fixes it demands

objective: >
  The nightly of 2026-09-18 failed on `shots_on_goal_pct` above 100% for two Europa League teams:
  the form-window mart gated that rate on shots-on-goal coverage alone and divided by total shots,
  which two play-off games lacked. `engineering_standards.md` §3.2 (merged in !201) rules the fix:
  a rate's gate is derived from every input of its formula, and one guard generated from the
  catalogue holds it. This MR builds that guard — two singular tests built at run time from
  `metric_catalogue.csv`, one per window surface (the form window `mart_team_momentum`, the season
  cumulative `int_team_season__metrics_cumulative`), each asserting that wherever a team rate is
  shown every input of its formula is present in every non-awarded game of its window — and fixes
  every gate the guard fails: per-input coverage counts in the two builders, every rate gated on
  the counts of its own inputs, the seven player-derived rates and `duels_won_pct` gated like the
  rest. The NULL sentence §3.1 requires on every rate is generated by `sync_metric_docs_blocks.py`,
  not typed. The plan was approved in plan mode on 2026-09-18.

decisions_taken: >
  The plan approved in plan mode on 2026-09-18. Taken as implementation of the ruled §3.2: the
  guard as two run-time-generated singular tests (one per window surface) rather than one file
  per rate; the availability predicate keyed on `base_relation` (a team-feed input is present
  when its column is non-null; a player-feed input is present when the game's
  `int_legs__team_from_players` row exists — `metric_layer.md`'s entity rule, written once);
  player-entity metrics outside the guard by that rule; a member-count floor so a renamed column
  cannot shrink the guard silently; per-input coverage counts named by input; `store_failures` on
  the two new tests. The seven player-derived rates and `duels_won_pct` follow the existing rule
  and go to "—" on partial player coverage — reserved to this step on !201, unobjected — at the
  measured cost above. The NULL sentence for every team rate generated by the docs-block sync,
  worded without "window" (the generator refuses that word by design) and without a file path.
