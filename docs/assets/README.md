## `screenshot.png` (referenced by the top-level README)

A screenshot of the live **Matchday IQ** MVP preview.

- **Format:** PNG
- **Recommended width:** ~1200 px (retina-friendly; scales down cleanly in the README)
- **Content:** a representative view of the app — ideally a fixture with its insights visible
- **Keep it current:** replace this when the v2 web app ships so the README never shows a stale UI

The same image (or a 1280×640 crop) can be reused for the GitHub **social preview**
(Settings → General → Social preview), which controls the card shown when the repo
is shared or surfaced in search.
